aws-bedrock-hermes-poc — Architecture

One OpenAI-compatible /v1 contract → proxy → Amazon Bedrock (model set via bedrock_model_id) → lineage + observability. Everything on AWS.

Client → Model

  • • Hermes / OpenAI SDK / A2A agents
  • • POST /v1/chat/completions (OpenAI shape)
  • • proxy translates to Bedrock, invokes the configured model
  • • same /v1 shape back — clients never change

Platform (AWS, us-east-1)

  • • VPC public subnets (no NAT / no ALB)
  • • ECS Fargate proxy · Lambda Function URL
  • • SSM Parameter Store · $5 budget alarm
  • • free-tier-safe · enterprise swap in reference

Observability + Lineage

  • • per-request lineage → S3 Object-Lock (WORM)
  • • CloudWatch model-invocation logs + metrics
  • • latency / error / token alarms + budget
  • • drift vs breakage vs decay (next slice)
